# MIREA — сайт производителя бытовой химии

Ультрасовременный сайт для компании Mirea (г. Дербент): гели для душа Sensa, жидкое мыло Aura, автошампунь Modul.

## Структура
- `index.html` — главный сайт (Hero, Компания, Продукция, Контакты, корзина, оптовые заявки)
- `admin.html` — админ-панель (товары/линейки/категории, клиенты, продажи, статистика)
- `api/send_order.php` → `order@mireacare.ru`
- `api/send_cooperation.php` → `cooperation@mireacare.ru`
- `.htaccess` — чистые URL

## Админ-панель
Логин: `admin` / Пароль: `mirea2024` (меняется в localStorage `mirea_admin_pass`)
Возможности:
- CRUD товаров, линеек, категорий
- Клиенты: ФИО, телефон, email, тип (физлицо/самозанятый/ИП/юрлицо), адрес, компания/ИНН
- Продажи: выбор товаров, сумма, тип оплаты (при получении/картой/по счёту/перевод/наличные)
- Статистика: периоды 1 день / 7 дней / месяц / год, топ товаров, по оплатам, по типам клиентов, Chart.js
- Лиды опта, экспорт CSV/JSON, демо-данные

Хранение: `localStorage` (mirea_products, mirea_sales, mirea_clients, mirea_leads) + дублирование в `data/orders.json` и `data/leads.json` через PHP на хостинге.

## Деплой на Timeweb (vh384.timeweb.ru)
1. Залейте файлы по FTP: хост `vh384.timeweb.ru`, логин `ruslan6635_mirea`, пароль `S6sMDxnR` — в корень сайта (обычно `/public_html` или `/www`).
2. Проверьте права на `data/` — 755 (создадутся автоматически).
3. Настройте почту:
   - В панели Timeweb → Почта → создайте ящики `order@mireacare.ru` и `cooperation@mireacare.ru` (если нет).
   - В `api/*.php` указан `$from = noreply@mireacare.ru` — замените на существующий ящик вашего домена, иначе письма могут попасть в спам. Рекомендуется создать `noreply@mireacare.ru`.
   - Для надёжности подключите SMTP (PHPMailer) если `mail()` не доходит — сообщите, настрою.
4. Проверка: откройте `https://ваш-домен/api/send_order.php` — должен ответить JSON.
5. Тест заказа: добавьте товар в корзину → Оформить → проверьте `order@mireacare.ru` и файл `data/orders.json`.

## Локальный запуск
Просто откройте `index.html` в браузере. PHP нужен только для отправки почты на хостинге.
